# 第二阶段锁定方案：执行前记录

这是已有数据探索后的方案冻结，不是事前注册。旧分析已使用美国记录至2019/2020及巴西全记录描述，因此任何重分割均不能追认成未接触过的确认性样本。

## 数据审计
对美国主队列276库逐一检查：成对有效非负日、重复日期、均值水量比、日极值相对库容、年度覆盖。|出/入流均值比|不在[0.1,10]，或任一日出流>1e6 m3/s，或单日出流体积>100倍库容，作为待核查标记而非错误判决。高误差库追加原始数据与上游ResOpsUS同日期比较；不给缺乏依据的值换单位。原始记录保留，所有标记库排除仅作为同规则敏感性。

## 假设（两项）
H1：跨时期入流均值的相对变化幅度越大，shape的跨时期绝对变化越大。
H2：入流的月分配变化越大，shape的跨时期绝对变化越大，在控制入流均值变化后仍然成立。
均值变化用|log(mean_late/mean_early)|；季节分配变化用12个月流量体积份额的总变差距离；响应abs(shape_late-shape_early)。多元线性模型报告原系数与主流域簇bootstrap 95%区间；两项同时推断使用各97.5%区间作保守家族误差控制。H1/H2系数预期正。解释变量包含后期入流，只用于事后机制一致性诊断，绝不作前瞻预测特征或因果识别。

## 固定时间验证
训练时间对为1980–1989→1990–1999水文年，测试时间对为2000–2009→2010–2019。每十年至少8合格年，每合格年>=90%配对有效日。训练标签截止1999，测试输入截止2009，测试目标始于2010。美国外层按MAIN_BAS留出：目标流域的任何训练时间对都不得进入训练。
主任务预测后期shape；均值、持续性、Ridge(alpha=10)、RF(200树,min_leaf=8,max_features=0.7,seed42)固定，不按测试结果调参。预测特征只取早期shape、meanratio、Q10signed、in_cv、零流差、入流月分配集中度和早期内部前5年/后5年入流趋势；不使用后期入流。比较MAE、R²、主流域等权MAE以及簇bootstrap配对误差差。对训练窗拟合H1/H2系数，并单独在测试窗估计方向和区间；不能把测试估计当训练。

## 外部复核与停止规则
如果巴西相同固定时间窗有足够记录，用美国训练时间对训练、巴西后期时间对测试；不因样本少移动窗口寻找好结果。巴西只作跨国家回顾性复核，不是随机抽样独立试验。无足够时期记录则明确记录不可行。
若冻结假设在测试期方向不稳定/区间跨零、预测不优于持续性，则不写机制发现或算法创新；重写为验证边界与局限的研究草稿，并明确新颖性仍需补证。真正未接触过的独立数据若无法公开获得，列为未完成项，禁止声称通过。
